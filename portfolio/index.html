AeroVision

Aug 2026 – Oct 2026

Finds defects on aircraft surfaces and answers maintenance questions about them, with every recommendation tied to a repair guide.

Python, OpenCV, YOLOv8, PyTorch, Groq Llama 3.3 70B, sentence-transformers, FAISS, Pydantic, Streamlit

What I built
  • A Streamlit system that detects and classifies four defect types (cracks, corrosion, dents, rivet damage) with OpenCV and an optional YOLOv8 backend, plus severity scoring, explainable heatmaps and scan-to-scan progression tracking.
  • A PyTorch LSTM that predicts engine remaining useful life on NASA C-MAPSS data, combined with the defect findings into one inspection record.
  • An LLM maintenance copilot: a RAG knowledge base of repair guidance (sentence-transformers and FAISS, filtered by defect type and severity) and a tool-calling agent on Groq Llama 3.3 70B, with a Gemini fallback, that runs the detector, severity, progression and life-prediction functions to answer questions like "is this scan worse than the last one?"
  • Grounded report generation: output is validated with Pydantic and checked against pipeline results, each recommendation must cite a retrieved guidance chunk, and failures fall back to a template. Retrieval quality is measured with hit@k and MRR.
